# AUCSimHerd Package
The package simulates the female part of a reindeer herd. The reindeer are individually simulated and both the calving probability and calf weight is allowed to be dependent on the mother's body weight. Selection on calf weights is allowed.

Install the package and get started using the following R commands on your computer:

library(devtools)  
devtools::install_github("larsronn/AUCSimHerd-Package")  
library(AUCSimHerd)  
?SimulateHerd
